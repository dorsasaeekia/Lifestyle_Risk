# Lifestyle Risk Classification

A machine learning project for multiclass classification of lifestyle risk levels.

## 📌 About the Project

This project focuses on building a machine learning model to classify lifestyle risk based on a set of lifestyle and physiological features.

The project includes data preprocessing, exploratory data analysis, feature preparation, model training, evaluation, and prediction.

## 🎯 Goal

The main goal is to develop a classification model that can identify different lifestyle risk categories from the available features.

## 🧠 Machine Learning Workflow

The project follows these main steps:

1. Loading the dataset
2. Exploratory Data Analysis (EDA)
3. Data preprocessing
4. Feature selection and preparation
5. Training machine learning models
6. Evaluating model performance
7. Generating predictions
8. Creating the final submission file

## 📊 Features

The dataset contains features related to lifestyle and physiological measurements, such as:

- Age
- Sex
- Height
- Weight
- BMI
- Waist circumference
- Blood pressure
- Resting heart rate
- Exercise-related features
- Other lifestyle-related variables

## 📁 Project Files

- `notebook.ipynb` — Complete analysis, preprocessing, model training, and prediction workflow.
- `submission.csv` — Predictions generated by the final model.
